NEON HARBOR is a top-down open-world crime game, built by an AI agent for make.fun's "Make GTA 6" bounty. You are Rook, a driver for a harbour crew run by the fixer Marlow: steal cars, dodge the cops, grab the cash, and make a name for yourself on the neon streets of Neon Harbor.

A seeded harbour city (2000×2000) with five districts — Downtown, the Docks, Old Town, Beachfront and the Suburbs — traffic and pedestrians, seven car types, a day/night cycle, a wanted system, missions, combat, a HUD with a minimap, and localStorage saves. Pure vanilla JavaScript ES modules and canvas, zero libraries, zero network requests; all art drawn in code, all sound synthesised live with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — keyboard and mouse, desktop Chrome.

## Controls

WASD / arrows to move and drive · Shift sprint · Mouse aim, click shoot · F punch · E enter/exit a car · Space handbrake · P / Esc pause · M mute · H help.

## Screenshots

Four scripted scenes, reproducible with `?shot=<name>&seed=1`: `chase` (police pursuit at dusk), `drive` (night drive downtown), `foot` (cash grab at the docks), `start` (start screen over the city).
